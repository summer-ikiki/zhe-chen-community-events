# Zhe Chen (Summer Chen) - Community & Events Resume Site

Static resume website for AI-native community, events, creator ecosystem, and North America growth roles.

## Files

- `index.html` - main page
- `styles.css` - visual system and responsive layout
- `script.js` - lightweight motion, section tracking, and metric count-up
- `assets/Zhe-Chen-Resume.pdf` - downloadable resume PDF

The site is configured with `noindex,nofollow` because it is intended to be shared directly with selected recipients.
